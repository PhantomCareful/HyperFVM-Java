# 功能列表
## 仪表盘：不需要进入游戏就可以查看各种重要信息。已接入以下内容：
### 置顶功能区
- App通知公告：非必要不出现，出现的大部分情况是App发生了功能变更，提醒您升级版本。
- 月末提醒：每月最后一天显示，提醒您清空积分和金券（QQ空间玩家的专属充值道具）。
- 温馨礼包：提供温馨礼包链接绑定、领取功能。
- 双爆信息：展示当天为限时双爆还是全天双爆，详细内容格式借鉴了提拉米鼠机器人。
- 更新公告：点击卡片可跳转官方在B站发布的最新更新公告。
- 每日签到：展示进度。
- 施肥活动：展示起止时间和进度。
- 福利打卡：展示起止时间、进度和新卡信息。
### 悬赏专区
- 美食悬赏：展示起止时间和进度。
- 声望翻倍：展示是否已开启翻倍和当日可获取的最大声望值。
- 抢红包：展示当天是否有抢红包活动。
### 肝帝专区
- 三岛福利：展示起止时间、进度和返场卡片名单。
- 美食大赛：展示起止时间、进度和返场卡片名单。
- 营地任务：展示起止时间和进度。
- 助人为乐：展示起止时间和进度。
- 欢乐假期：展示起止时间、进度和返场卡片名单。
- 巅峰对决(世界BOSS)：展示当前赛季的重要时间节点和进度。
### 打折专区
- 二转打折：展示起止时间、进度和参与卡片名单。
- 结晶强化打折：展示起止时间和进度。
- 豪华婚礼打折：展示起止时间和进度。
### 氪金专区
- 日氪：展示起止时间和进度（以日氪道具数量的形式展示）。
- 百万消费：展示起止时间和进度。
## 特色功能
### 防御卡全能数据库：把陌路老师的防御卡数据文档封装成一个可查询的数据库。已封装以下数据：
- 大图片：该卡片的高清形象。
- 基础信息：该卡片在游戏面板上各个形态的名字和能力描述、体力、冷却时间、在数据图中的所属分类（位于哪张数据图的哪个部分）、耗能、作为副卡（好卡、中卡、差卡）。
- 人话解释：用直接简练的语句说明转职之后发生的变化。
- 相关卡片：对应的金卡、融合卡、增幅卡、增幅名单。
- 数据信息：星级数据、金卡援护、品阶数据、技能数据、技能点数据、分解兑换数据（内置分解兑换计算器）。
- 其他信息：各种属性（穿透、减速等等）、图鉴加成、食神谱信息、一堆附加说明。
### 数据图合集
- 收录部分提拉米鼠生成的最新数据图、陌路老师制作的所有数据图和一些自制数据图。
### 食神谱合集：为每个食神谱设计了专属的介绍界面。已封装以下内容：
- 基础信息：食神谱名字、图片、类型、奖励食神点、游戏内描述。
- 获取途径：总结每个食神谱可以从哪里获得。
- 合成材料：所需的卡片和对应星级。点击可以直接跳转到这张卡片的数据详情界面。
- 增益内容和卡片名单：点击可以直接跳转到这张卡片的数据详情界面。
### 宝箱概率公示合集：将部分官方已经发布出来的概率公示收集起来，方便查看。
## 美食数据站
### 收录各种实用网站、共享文档的入口，点击相应的卡片即可快捷跳转浏览器访问。已收录以下网站和共享文档：
- 提拉米鼠使用指南
- 陌路の综合数据表
- FAA米苏物流
- 卡片鼠军对策表
- 巅峰对决部分机制解析
- 强卡最优路径计算器
- 宝石最优路径计算器
- FVM查黑系统（提供本地UI，无需跳转网页）
## 实用工具
### 今日运势
- 里面是多张以不同速率播放的、包含不同星级海星的动图，点击按钮可以暂停动图，并根据星级计算得分。
### 威望储备计算器
- 输入您游戏内不同面额威望币的数量，帮您计算当前一共有多少威望。
### 强卡成功率计算器
- 可完美模拟出游戏内合成屋的卡片强化概率计算功能。

# 安装
### 支持的系统环境
- ✅Android：支持Android12-17。
- ✅HarmonyOS：支持鸿蒙3-4.3，鸿蒙Next需要在卓易通环境下才能使用，请自行测试。
- ❌不支持Windows、iOS，感谢大家的理解。
